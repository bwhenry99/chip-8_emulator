# Chip-8_emulator


## Introduction
The Chip-8 was an interpreter that allowed users to create their own games and programs using a simplified set of intructions on the COSMAC VIP created in 1977. This project is a C++ implentation of an interpreter that strives to emulate the performance of the original interpreter, primarily as an introduction hardware emulation. More information about the Chip-8 and a guide for creating your own emulator can be found at Tobias V. I. Langhoff's blog [here](https://tobiasvl.github.io/blog/write-a-chip-8-emulator/#specifications).

## Install
The supplied CMake files should handle all required build setup to confiure a C++ project for your target system.
